# ACAAN playing-card artwork sources

- Court face SVGs (`jack_of_*.svg`, `queen_of_*.svg`, `king_of_*.svg`) sourced from [Webisso/playing-cards](https://github.com/Webisso/playing-cards), MIT licensed, which itself references public-domain vector-playing-cards by Byron Knoll. Original MIT licensing and provenance available at the source repository.
- These are hosted locally in this repository so spectator-facing runtime is not dependent on the upstream asset site.
- The photo-like wooden backdrop, natural paper texture, and camera/perspective coherence are still QC work, not represented as final photographic assets.
- Image/logo paths never contain user personal data or performer authentication tokens.
